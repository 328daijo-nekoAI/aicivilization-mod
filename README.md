# AI Civilization Mod（開発中・フェーズ1〜3実装版）

Minecraft Forge 1.20.1 用の、Groq APIを使ったAI文明シミュレーションMod。

## これは何？

AIたちがGroq APIを「脳」として、結婚・離婚・出産・会話などを自律的に
判断しながら文明を築いていくMod。導入は `.jar` を `mods` フォルダに
入れるだけ（ビルド後）。

## 現在実装済みの機能（全フェーズ）

- Groq APIキーを「脳」としてゲーム内GUIおよびブラウザから登録・管理（config編集不要）
- AI 1体につき脳を1〜5個割り当て（0個ではスポーン不可）
- 名前の重複回避システム
- AIエンティティのスポーン（`/aicivilization spawn` コマンド or 創造の杖アイテム）
- Groq API への非同期呼び出しとレート制限対策（クールダウン制御、複数脳のラウンドロビン）
- AIの思考結果をチャットに表示、記憶ファイル（JSON）への記録・要約圧縮
- 結婚・離婚の判定と成立処理
- 出産・子供の誕生・成長システム（成長時に新規APIプロファイルを消費し、
  子供時代の記憶を引き継ぐ）
- 建築システム（AIが「家がほしい」と発言すると自律的に簡易な家を建てる）
- 経済システム（職業に応じた収入、AI間の簡易取引）
- 政治システム（人口が一定数を超えると村長選挙が自動発生）
- 宗教システム（幸福度の高いAIが信仰を立ち上げ、周囲が信者になることがある）
- 戦争システム（異なる信仰・低信頼度のAI間で武力衝突が発生することがある）
- 文明全体のイベントログ（`/aicivilization log` で確認、ダッシュボードでも閲覧可）
- HTMLブラウザ管理ダッシュボード（`http://localhost:25580`）
  - 脳（APIプロファイル）の追加・削除
  - 個体別記憶ファイルの閲覧・編集
  - 文明全体ログの閲覧

## 未検証・要注意事項

- **このコードは実機で一度もビルド・動作確認をしていません。** Forge 1.20.1 API の
  細かいメソッド名の違いなどにより、`./gradlew build` でコンパイルエラーが出る
  可能性があります。実際に動かす際は、エラーメッセージを見ながら修正が必要になる
  前提で臨んでください
- AIの「行動意図の読み取り」は簡易的なキーワードマッチングです（本格的な自然言語
  理解ではありません）。Groqの応答が期待した形式でない場合、行動に反映されない
  ことがあります
- 大人数のAIを動かすとGroq無料枠のレート制限に引っかかりやすくなります

## ビルド方法（GitHub Actionsで自動ビルド・コマンド操作不要）

自分のPCでビルドコマンドを打つ必要はありません。GitHubというサービスに
このコードを置くだけで、自動的にビルドされ、完成した `.jar` ファイルが
ダウンロードできるようになります。

### 手順

1. **GitHubアカウントを作る**（無料）
   https://github.com/ にアクセスし、「Sign up」からアカウントを作成

2. **新しいリポジトリ（保管場所）を作る**
   - 右上の「+」→「New repository」
   - Repository name に `aicivilization-mod` などお好きな名前を入力
   - 「Public」のまま「Create repository」をクリック

3. **このZIPの中身をアップロードする**
   - 作成されたリポジトリのページで「uploading an existing file」というリンクをクリック
   - このZIPを解凍してできた `aicivilization` フォルダの中身（`src`フォルダや
     `build.gradle` など）をすべてドラッグ＆ドロップ
   - 隠しフォルダの `.github` フォルダも忘れずにアップロード
     （表示されていない場合は、フォルダごとドラッグすれば含まれます）
   - 下の「Commit changes」ボタンをクリック

4. **自動ビルドが始まるのを待つ**
   - リポジトリページ上部の「Actions」タブをクリック
   - 「Build AI Civilization Mod」という項目が実行中（黄色い丸）になっているはず
   - 数分待つと、緑のチェックマーク（成功）または赤い×（失敗）になる

5. **完成したjarファイルをダウンロードする**
   - 緑のチェックマークが付いた実行結果をクリック
   - ページ下部の「Artifacts」欄にある `aicivilization-mod-jar` をクリックすると
     ZIPがダウンロードされる
   - 解凍すると中に `.jar` ファイルがある。これが完成品

6. **`.jar` を `mods` フォルダに入れる**
   - Forge 1.20.1本体を導入した上で、`.minecraft/mods/` フォルダに
     ダウンロードした `.jar` を入れる

### もしビルドが失敗（赤い×）した場合

- 同じ「Artifacts」欄に `build-logs` というファイルもあるので、それをダウンロードして
  エラー内容を見る（またはそのエラーメッセージをそのままこちらに貼っていただければ
  一緒に直します）
- Forge 1.20.1のAPIとコードの間で細かい不一致がある可能性が高く、
  1〜2箇所の修正で直ることが多いです

## 使い方

1. ワールドに参加すると案内メッセージが表示される
2. `/aicivilization brains` で脳（Groq APIキー）を登録
   - Groq APIキーは https://console.groq.com/ から無料で取得可能
3. `/aicivilization spawn` でAIを出現させる（未割当の脳を1〜5個選択）
4. AIたちが自律的に会話・行動を始める（チャットに発言が表示される）
5. `/aicivilization log` で文明の出来事（結婚・出産等）を確認

## 注意事項

- Groq APIキーは無料枠がありますが、レート制限があります。
  AIの人数を増やしすぎると制限に引っかかりやすくなります
- 現状は「Forge Mod」形式のみ対応（データパック単体では外部API通信が
  できないため）
